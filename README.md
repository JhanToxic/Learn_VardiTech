# Портфоліо

Статичний сайт-портфоліо на HTML і CSS, готовий до публікації через GitHub Pages.

## Публікація через GitHub Pages

1. Запуште репозиторій на GitHub.
2. Відкрийте `Settings` → `Pages`.
3. У `Build and deployment` виберіть `Deploy from a branch`.
4. Вкажіть гілку `main` і папку `/ (root)`, потім натисніть `Save`.

GitHub Pages використовує `index.html` як головну сторінку. Після публікації сайт буде доступний за адресою:

`https://<ваш-логін>.github.io/<назва-репозиторію>/`
